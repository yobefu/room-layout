# 部屋の動線メモ（フェーズ1）

部屋の「片付け」と「動線（人が部屋の中を移動する道筋）」を改善するためのブラウザアプリです。
写真や手書き図を下絵にして間取りを作り、1日の移動距離・通路の幅・片付けの警告・家具の置き方の提案を出します。

## 使い方

### PC（Windows・Chrome / Edge）
- `index.html` をダブルクリックすると開きます。
- この開き方でも、ノートPCのカメラで撮影できます（初回にカメラの使用許可を求められます）。
- この開き方では、ホーム画面への追加とオフライン起動の機能は働きません（普通の Web ページとしては問題なく動きます）。

### iPhone・iPad（GitHub Pages で公開して使う）
iPhone・iPad では HTML ファイルを直接開いても動かないため、Web 上に置きます。

1. GitHub のアカウントを作る（無料）。
2. 新しいリポジトリ（プログラムの置き場）を作り、この `room-layout` フォルダの中身をすべて入れる。
   - Git を使う場合は、このフォルダで次のコマンドを実行する（`<ユーザー名>` と `<リポジトリ名>` は自分のものに置き換える）。
     ```
     git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
     git push -u origin master
     ```
   - Git を使わない場合は、GitHub の画面の「Add file → Upload files」からファイルをまとめてアップロードする。
3. リポジトリの「Settings → Pages」で、Branch に `master`（フォルダは `/ (root)`）を選んで Save。
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになる。
5. iPhone・iPad の Safari でその URL を開き、共有ボタン →「ホーム画面に追加」。次からはホーム画面のアイコンから起動する（電波がなくても起動できる）。

注意
- 無料プランでは、リポジトリは誰でも見られる状態になります。公開されるのはアプリのプログラムだけで、写真や部屋のデータはサーバーに送られません（すべて端末の中で処理・保存します）。
- iPhone・iPad では、**ホーム画面のアイコンから開いたときと、Safari で URL を開いたときで、保存場所が別**になります。普段はホーム画面のアイコンから開いてください。
- アプリを更新したら、`sw.js` の `CACHE_NAME` の番号を上げてください（端末に保存された古いファイルが入れ替わります）。

### はじめ方
最初に開くと「はじめ方を選ぶ」が出ます（あとで「新規」ボタンからも選べます）。
- **写真から（おすすめ）**：床の写真を下絵にして、その上をなぞって家具を置く。
- **手書き図から**：手書きの間取り図を下絵にする（写真の補助）。
- **空の部屋から手入力**：家具を1つずつ追加する。
- **見本を見る**：整理整頓の見本の部屋を読み込む。

### 写真・手書き図の取り込み（「取り込み」タブ）
1. 「写真を選ぶ」か「カメラで撮影」を押す。
2. 画像の上で、床の四角形の4つの角を **1 左上 → 2 右上 → 3 右下 → 4 左下** の順に押す（アプリの間取り図で見たときの向き）。押した後はドラッグで直せる。
   - 写真：部屋の4隅、ラグ、メジャーで測った範囲など、**大きさが分かっている床の四角形**を選ぶ。背の高い家具は傾いて写るので、角は床に接している所を選ぶ。
   - 手書き図：部屋の4隅を押す。横向きに撮った図でも、押す順番で向きがそろう（「画像を90度回転」でも回せる）。
3. 四角形の大きさ（cm）を入れて「下絵にする」。
4. 「なぞって家具を追加」がオンになるので、家具の**足元**をドラッグで四角に囲むと家具として登録できる。

### JSON の保存・読み込み
- 配置はブラウザの中（localStorage）に自動で保存され、再読み込みしても戻ります。
- 保存場所は「開いた場所」ごとに別です。PC と iPad など機器の間で移すときは：
  1. 「JSON 書き出し」（下絵の画像を含めるか選べる。iPhone・iPad では共有シートから AirDrop や「ファイルに保存」）
  2. 受け取った機器で「JSON 読み込み」
- 保存容量は約 5MB です。下絵の画像が大半を使うので、増えすぎたら不要な下絵を削除してください。

### 計算部分のテスト
```
node --test room-layout/test/
```
（`room-layout` の1つ上のフォルダで実行）

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目 |
| `logic.js` | 計算部分（方眼化・A*・通路幅・スコア・片付け・提案・射影変換）。画面の操作を含めない |
| `import.js` | 写真・手書き図の取り込み、カメラ撮影、4点指定、補正 |
| `app.js` | 画面の操作・描画・保存 |
| `sample-data.js` | 見本データ |
| `manifest.json` / `sw.js` / `icon-*.png` | ホーム画面に追加・オフライン起動（PWA） |
| `test/logic.test.js` | 計算部分のテスト |

調整しそうな数値は、`logic.js`・`import.js`・`app.js` の冒頭の定数にまとめてあります。
